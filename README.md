# Let'sVote

**Let'sVote** is a multi-campaign online voting and competition management platform.

It helps organizations create voting campaigns, organize categories and entries, collect authenticated votes, and publish transparent results.

## Project status

This repository is being initialized. The first delivery focuses on product definition and technical planning before implementation.

## Documentation

The project blueprint will live in [`docs/`](docs/README.md).

## Planned technology

- Frontend: React + TypeScript
- Backend: C# / ASP.NET Core Web API
- Database: PostgreSQL + Entity Framework Core
- Architecture: Modular Monolith with Clean Architecture principles
- Testing: xUnit + integration tests against PostgreSQL
- Delivery: Docker, GitHub Actions, and a public demo deployment

## Product principle

Build a reliable, understandable MVP first. Prioritize vote integrity, authorization, data consistency, and testability over premature infrastructure complexity.
