# Let'sVote Documentation

This directory contains the product and engineering blueprint for Let'sVote.

## Reading order
1. [Product Requirements](01-PRODUCT-REQUIREMENTS.md) — vision, actors, scope, workflows, business rules, acceptance criteria.
2. [System Architecture](02-SYSTEM-ARCHITECTURE.md) — architecture style, components, boundaries, technology choices.
3. [Database Design](03-DATABASE-DESIGN.md) — entities, relationships, constraints, indexes, data integrity.
4. [API Specification](04-API-SPECIFICATION.md) — REST conventions, endpoint plan, payloads, errors.
5. [Security Design](05-SECURITY-DESIGN.md) — authentication, authorization, vote integrity, abuse controls.
6. [Implementation Roadmap](06-IMPLEMENTATION-ROADMAP.md) — milestones, backlog, Definition of Done.
7. [Technical Decisions](07-TECHNICAL-DECISIONS.md) — decisions, rationale, open questions.

Status terms: Planned = agreed direction, not necessarily implemented; MVP = required for first public demo; Deferred = excluded from first release; Open = decision required before implementation.

> These documents describe the intended system. They are not evidence that a feature has already been implemented.
